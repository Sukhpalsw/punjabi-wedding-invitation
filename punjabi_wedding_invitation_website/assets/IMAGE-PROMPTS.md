# Image Prompts — Missing Photos

No image-generation API or tool is configured in this project (there is no
`package.json`, `.env`, or similar config file, and none of my available
tools can generate images). So nothing was generated automatically, and I
did not need to ask for API access.

Every photo below is currently missing from `assets/`. The site already
displays an elegant styled placeholder ("✦ Photo coming soon ✦") wherever
one of these is absent, so the website stays fully usable in the meantime.

Use these prompts with whichever AI image tool you prefer (Midjourney,
DALL·E, Stable Diffusion, Adobe Firefly, etc.), or replace them with your
own real photography — real photos will always look better and more
personal than AI-generated ones for a wedding invitation. Save each result
into `assets/` using the exact filename listed so the site picks it up
automatically with no code changes.

A general negative-prompt note for all of them: avoid any text, captions,
watermarks, logos, or distorted hands/faces — request "no text, no
watermark" explicitly, and regenerate if hands or jewelry look warped.
